# Contributing

Bug reports and contributions are welcome in English or Brazilian Portuguese.

## Report a bug

[Open an issue](https://github.com/tbrondani/grandma-linux-kinoite-post-install/issues). Include:

1. Your Fedora and KDE Plasma versions.
2. Steps to reproduce the problem.
3. Expected and actual results, with relevant logs or screenshots.

Remove passwords and personal information. For security issues, see [SECURITY.md](SECURITY.md).

## Propose a change

1. Create a branch from main.
2. Make a focused change and update both language versions where needed.
3. Open a pull request. Describe the problem, the change, and how you tested it.

Use English for commits and pull request descriptions. Include repeat-run results for setup changes and screenshots for desktop changes. Credit added dependencies in [THIRD_PARTY.md](THIRD_PARTY.md).

All changes to main go through pull requests. See [TESTING.md](TESTING.md) before a release.

## Donations

Please support the upstream projects listed in [THIRD_PARTY.md](THIRD_PARTY.md). The maintainer does not seek income from Grandma Linux.
