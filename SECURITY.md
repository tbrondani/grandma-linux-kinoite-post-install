# Security reports

There are no supported releases yet.

Do not post passwords, personal data, or exploit details in public issues.

Use [GitHub private vulnerability reporting](https://github.com/tbrondani/grandma-linux-kinoite-post-install/security/advisories/new) if it is available. If unavailable, open an issue asking the maintainer for a private contact, without disclosing the vulnerability.

Include the affected version, impact, and reproduction steps. Reports are welcome in English or Brazilian Portuguese. Response times are not guaranteed for this hobby project.
