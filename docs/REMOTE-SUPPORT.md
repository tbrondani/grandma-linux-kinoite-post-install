# Remote support

1. Open **Help → Remote Support**. Share the ID and temporary password with your trusted helper.
2. Approve screen sharing when KDE asks.
3. Close the window when finished. The project launcher stops every RustDesk process.

The project profile has no auto-start or permanent-password access.

A real incoming connection and Wayland permissions still need a test with a second machine. Upstream RustDesk may stay in the tray; use the project's **Remote Support** launcher.
