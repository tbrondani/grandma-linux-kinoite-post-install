# Reading comfort

Open **System → Reading comfort**. Choose Atkinson Hyperlegible Next at 12 or 14 pt. The preset also uses a 32 px pointer. Reopen applications to see font changes; some pointer changes need a new login. Select **Restore previous font and pointer size** to undo these settings. Other desktop settings are preserved.

Setup installs the font but keeps the current desktop font. Project updates do not select a reading preset. The manual has separate text-size controls. Browser pages and sandboxed apps may use their own fonts.

Compare `I l 1`, `O 0`, `B 8`, and Portuguese accents at a normal reading distance on the actual monitor. Start with Regular 12 pt; compare 14 pt, then adjust the screen scale in Display Settings if needed. Font preference depends on the reader and display. This is a readability option, not a treatment for myopia or astigmatism.

The [Braille Institute](https://www.brailleinstitute.org/freefont/) designed Atkinson Hyperlegible Next around distinct letterforms. Its unchanged font files and OFL license are pinned in `data/reading-fonts.json`. The current Aero menu already has an opaque backing layer; avoid changing that while comparing text.
